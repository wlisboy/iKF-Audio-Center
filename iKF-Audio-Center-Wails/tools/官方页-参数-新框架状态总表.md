## 一、驱动参数层结论

**无遗漏**。`names.go` 的 208 个属性名全部能在 `osConfLib.dll` 字符串表找到；DLL 多出来的只有 `EnableEX`/`EnableGFS`（= HKCU `C-Media\Hook` 注册表值，已由 `GFSControl` 覆盖）和导入 API 名。

## 二、A 组 · 驱动参数存在、新框架无正式控件

状态口径：
- **仅参数页**：名字在 208 表 →「参数」开发者页可见；但**未登记 `writable`**，参数页显示 w=false，写了也是白写（铁律 1）。
- **接 UI 门槛**：登记两端白名单（`driver.go` writable + Python 侧 `WRITABLE`）→ 写探测实测 → 再做控件。
- **写探测未做**：下表值域/可写性凡未实测的，一律不预设结论（UNPROVEN 纪律）。
